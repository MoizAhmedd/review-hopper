Privacy

Effective October 15, 2026.

Review Hopper doesn't collect, send, sell or share any information about you or the code you review. There are no accounts, analytics or ads, and no Review Hopper server. It works entirely in your browser.

Where it runs

Only on gitlab.com and github.com, and it only acts on merge request and pull request review pages. On other pages of those sites it does nothing.

What it reads

  • The list of changed files the review page already shows.
  • The old and new versions of some of those files (dependency manifests and lockfiles, database migrations and schemas, Dockerfiles, CI config, API specs and markdown), downloaded from the same site with the login you already have, so it can summarise or render them.

Everything it reads is processed inside your browser.

What it stores

  • Your settings from the toolbar popup, synced across your browsers if you use Chrome sync.
  • The summaries it makes, kept in memory for the browser session so a review you reopen loads instantly. They're cleared when Chrome quits.

What it sends

Nothing, unless you ask. When you write a comment on a rendered document and click Comment, Review Hopper posts that comment to the merge request through GitLab's own API, exactly as if you had written it in GitLab.

Permissions

  • Access to gitlab.com and github.com: to change the review pages and read the files in a review.
  • Storage: for your settings and the session's summaries.
